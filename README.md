# Электронный кошелёк (Flutter + Codemagic)

Кроссплатформенное мобильное приложение на фреймворке Flutter для автоматического распределения личного бюджета и контроля расходов, поддерживающее сборку под операционные системы Android и iOS.

## Бизнес-логика и распределение средств

Каждый раз, когда пользователь добавляет денежные средства в систему, внесенная сумма автоматически распределяется по четырем целевым направлениям:

| Целевое направление | Процентное соотношение | Функциональное назначение |
| :--- | :---: | :--- |
| **Ежедневные расходы** | **50%** | Формирует базовый бюджет, распределяемый на 30-дневный период. |
| **Накопления** | **25%** | Автономный накопительный баланс («карман»), изолированный от трат. |
| **Резерв** | **15%** | Стаховой фонд для непредвиденных обстоятельств. |
| **Другие потребности** | **10%** | Дополнительный фонд для второстепенных нужд. |

### Правила расчета ежедневного лимита (доля 50%)
* Суммарный выделенный бюджет на текущий период делится ровно на 30 дней, формируя фиксированный **дневной лимит**.
* В течение дня пользователь фиксирует фактически потраченные суммы.
* При превышении дневного лимита интерфейс отображает сумму перерасхода, продолжая фиксировать транзакции.
* Неизрасходованный за сутки остаток лимита не сгорает, а переносится на следующие дни, увеличивая доступный баланс внутри периода.
* При добавлении средств в рамках активного 30-дневного цикла, они увеличивают баланс только текущего периода, после чего система осуществляет мгновенный перерасчет дневного лимита до конца текущего цикла.
* После завершения 30-дневного цикла остаток переносится на новый период и суммируется с новыми поступлениями.

> **Важная особенность:** Если текущий период завершается с отрицательным балансом (дефицит бюджета), следующий 30-дневный цикл принудительно стартует с **0**. Величина дефицита фиксируется и выводится в интерфейсе в графе *«Превышение лимита предыдущего периода»*, исключая перенос долговой нагрузки на новый операционный месяц.

## Дизайн и архитектурные решения

* **Визуальный стиль:** Строгий интерфейс в стиле iOS с использованием контрастных элементов. Основной корпоративный цвет — тёмно-зелёный (`#0B4D2C`), фон — чистый белый.
* **Автономность:** Локальное сохранение состояния и истории транзакций на устройстве пользователя с помощью плагина `shared_preferences`. Приложение полностью функционально без доступа к сети Интернет.


## Конфигурация зависимостей (pubspec.yaml)

Данная конфигурация является универсальной и используется для инициализации библиотек на обеих целевых платформах.

```yaml
name: elektron_hamyon
description: "Elektron Hamyon - Смарт-кошелек с автоматическим распределением бюджета."
publish_to: 'none'

version: 1.0.0+1

environment:
  sdk: '>=3.0.0 <4.0.0'

dependencies:
  flutter:
    sdk: flutter

  # Локальное сохранение данных (баланс, карманы, транзакции)
  shared_preferences: ^2.2.3

  # Работа с датами (контроль 30-дневного периода) и форматирование валют
  intl: ^0.19.0

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^3.0.0

flutter:
  uses-material-design: true
```

* **Валидация отступов:** Файлы YAML критичны к структуре переносимых строк. Использование знака табуляции (Tab) запрещено. Все отступы должны формироваться исключительно с помощью пробелов.
* **Инициализация пакетов:** После добавления конфигурации выполните в корневом каталоге проекта команду:
  ```bash
  flutter pub get
  ```

## Автоматизация сборки в Codemagic (codemagic.yaml)

Ниже представлены рабочие конфигурационные сценарии для платформы Codemagic. Вы можете использовать только необходимый вам блок в зависимости от целевой платформы, чтобы избежать ошибок тарификации.

### Вариант 1. Конфигурация сборки ТОЛЬКО для Android

Данный сценарий предназначен для компиляции установочного файла `.apk` и релизного бандла `.aab` на бесплатных мощностях macOS-серверов.

```yaml
workflows:
  # ============== ANDROID ==============
  android-workflow:
    name: Elektron Hamyon - Android
    max_build_duration: 60
    instance_type: mac_mini_m1
    environment:
      flutter: stable
      vars:
        PACKAGE_NAME: "com.woodera.elektronhamyon"
    scripts:
      - name: Flutter paketlarni o'rnatish
        script: |
          flutter packages pub get
      - name: Android uchun APK yig'ish (release)
        script: |
          flutter build apk --release
      - name: Android uchun AAB yig'ish (Play Store uchun, release)
        script: |
          flutter build appbundle --release
    artifacts:
      - build/app/outputs/flutter-apk/*.apk
      - build/app/outputs/bundle/release/*.aab
    publishing:
      email:
        recipients:
          - nackroot.uz@gmail.com
        notify:
          success: true
          failure: true
```

#### Инструкция по сборке Android
1. Авторизуйтесь на [Codemagic](https://codemagic.io/) через ваш Git-провайдер и подключите репозиторий.
2. В строке **«Select file workflow»** укажите `Elektron Hamyon - Android`.
3. Запустите процесс кнопкой **«Start new build»**.
4. По завершении (2–3 минуты) перейдите в блок **Artifacts** внизу страницы и скачайте файл с расширением `.apk` для прямой установки на смартфон.

### Вариант 2. Конфигурация сборки ТОЛЬКО для iOS (Без платной подписи)

Данный сценарий компилирует iOS-версию приложения без необходимости покупки платного аккаунта разработчика Apple Developer (\$99/год). На выходе генерируется архив приложения для тестирования на симуляторах или альтернативной установки.

```yaml
workflows:
  # ============== IOS ==============
  ios-workflow:
    name: Elektron Hamyon - iOS
    max_build_duration: 60
    instance_type: mac_mini_m1
    environment:
      flutter: stable
      xcode: latest
      cocoapods: default
      vars:
        BUNDLE_ID: "com.woodera.elektronhamyon"
        XCODE_WORKSPACE: "Runner.xcworkspace"
        XCODE_SCHEME: "Runner"
    scripts:
      - name: Flutter paketlarni o'rnatish
        script: |
          flutter packages pub get
      - name: SBORKA iOS (Bez sertifikatov)
        script: |
          flutter build ios --release --no-codesign
    artifacts:
      - build/ios/iphoneos/*.app
      - /tmp/xcodebuild_logs/*.log
    publishing:
      email:
        recipients:
          - nackroot.uz@gmail.com
        notify:
          success: true
          failure: true
```

#### Инструкция по сборке и развертыванию iOS
1. Запустите сборку в Codemagic, выбрав рабочий процесс `Elektron Hamyon - iOS`.
2. После успешного завершения скачайте архив `Runner.app.zip` из раздела **Artifacts**.
3. Для бесплатной установки на физический iPhone брата выполните ручную конвертацию в `.ipa`:
   * Распакуйте `Runner.app.zip`, вы выделите папку `Runner.app`.
   * Создайте новую папку с именем `Payload` (строго с большой буквы).
   * Переместите папку `Runner.app` внутрь созданной папки `Payload`.
   * Заархивируйте папку `Payload` обратно в ZIP-формат.
   * Переименуйте расширение полученного файла из `.zip` в `.ipa`.
4. Установите готовый `.ipa` файл на iPhone бесплатно с помощью ПК через **Sideloadly / AltStore** (сброс каждые 7 дней) либо напрямую с телефона через сторонние менеджеры сертификатов (**Scarlet / ESign**).
